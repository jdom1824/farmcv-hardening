# FarmCV source provenance

This public repository is an independently initialized publication copy of a local FarmCV source snapshot. The source snapshot did not include verifiable upstream Git metadata, so the initial commit records the contents of that snapshot and does not claim to reproduce or identify any deployed release or production commit.

The publication copy excludes runtime configuration, credentials, encryption keys, databases, uploaded photographs, caches, and test outputs. Local validation used synthetic data and a disposable development blockchain; no production credentials or user data are part of this repository.

The source files may differ from any running deployment. Review the release and deployment procedures independently before operating this software.
